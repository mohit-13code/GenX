# GenX implementation plan

Build a browser-only educational laboratory with a typed, deterministic engine independent of React. Implement and verify the core first, then connect all five problems, reversible playback, comparison and inspection. Finish with desktop/mobile browser checks and documentation. No external publishing or repository pushes.

- [x] P0: scaffold, seeded engine, binary and TSP problems, operators and numerical verification
- [x] P0: application shell, parameters, playback, explanations, landscape and charts
- [x] P1: knapsack, N-Queens, phrase, microscope, history, battle, diversity
- [x] P2: ancestry, manual learning, exports/imports, educational content
- [x] Verification: 38 unit tests, type checking, lint, 30 desktop/mobile browser tests, visual inspection, production build
- [x] Delivery: README, algorithm formulas, independent verification, demo script and deployment instructions

Optional scope omitted explicitly: historical experiment forks, multi-seed statistical trials, PMX and custom expressions. No navigation or buttons advertise unavailable functions. Full timelines remain in memory while the lab is mounted; configuration and preference persistence is local. External repository creation, pushes and deployment were not authorized by the brief and were not performed.
